# M1-LIVE: живой агентский цикл PIA замкнут (2026-10-06, ночь)

## Финальный прогон (glm-5.3-flash @ z.ai, Responses-API, из ABAP внутри OSG :8020)

```
PIA M1: live agent run
ANSWER: Fixed: `ADD` now returns `a + b`; class activated (selfcheck should pass).
RESULT: iters=4 tool_calls=3 ok=X err=
[read_object]  ok=X  {"name":"ZCL_PIA_DEMO"}
[write_source] ok=X  полный исходник с фиксом a + b
[activate]     ok=X
```
Позавчерний прогон: iters=5/4 колла, с самокоррекцией (пустые args → ошибка тула → повтор).

## Что доказано end-to-end

LLM (z.ai glm-5.3-flash) → executor → registry → tools → store-seam (WRITE/ACTIVATE из ABAP) → файл в дереве → внешний publish → verify PASS. Полный разговорный replay (function_call / function_call_output) через Responses-API.

## Три корневых бага, убитых по пути (все — квирки связки)

1. **Пробел съедался** в `Authorization: Bearer` (set_header_field) → z.ai code 1000 Auth Failed. Фикс: template `|Bearer { key }|`. Найден дампом запроса (OSD_LIB_OVERRIDE + fs.appendFileSync в дев-копии клиента).
2. **Хойстинг VALUE в циклах транспилятора**: `DATA lv_depth VALUE 1` не переинициализируется → split_entries выдавал 15 мусорных `{`; `DATA lt_p/lt_r` в registry копились между тула́ми → дубли параметров → 400 invalid JSON/API parameter. Фикс: явные присваивания/CLEAR.
3. **\uXXXX не декодировался** (`=u003e` вместо `=>` в записанном исходнике). Фикс: ветка `u` в unescape (003e/003c/0026/0027/0022).

## Найки ОСГ (для коллеги)

- «сломанный исходник активируется молча» — 3-й случай (`=u003e` прошёл ACTIVATE, ok=X). CHECKRUN должен ловить.
- warm-push (lock→PUT→ACT ~5-11 c) работает отлично для правок классов; watcher для файловых правок умирает после перезагрузки генерации.
